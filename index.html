Chave da API

Cada pessoa usa a própria chave do YouTube Data API v3. Ela fica salva só no seu navegador e não vai para este site nem para o GitHub.

Cota

10.000 unidades por dia, grátis. Cada palavra-chave × duração custa ~100. Analisar um canal pelo link custa ~3–10.

Testar sem gastar cota

Abra dark.html?teste ou musica.html?teste: usa dados simulados.
